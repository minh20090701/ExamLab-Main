EXAMLAB · Sửa lỗi Xóa đề

Công cụ vá trực tiếp trên ZIP mã nguồn hiện tại, không thay đổi chức năng khác. Chạy hoàn toàn trong máy của bạn.

  1. Vào GitHub ExamLab-Main → Code → Download ZIP.
  2. Chọn ZIP vừa tải ở bên dưới.
  3. Nhấn tạo bản vá, giải nén ZIP kết quả.
  4. Chạy SQL trong Supabase trước, rồi tải lại admin.html và js/admin.js lên GitHub.
Chưa chọn tệp.

Lưu ý: Hãy sao lưu database trước khi xóa đề thật. Bản này kiểm tra quyền Admin ở Supabase.
