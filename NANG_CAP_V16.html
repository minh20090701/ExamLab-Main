EXAMLAB · Nâng cấp V16

Đúng/Sai (2–5 ý) và chấm điểm theo từng phần. Công cụ chạy ngay trong trình duyệt, không gửi ZIP lên máy chủ.

  1. Vào GitHub ExamLab-Main → Code → Download ZIP để lấy mã mới nhất.
  2. Bấm chọn ZIP GitHub vừa tải ở dưới.
  3. Bấm Tạo bản cập nhật V16 để tải ZIP gồm 6 file đã sửa và một đề mẫu.
  4. Giải nén ZIP mới, upload các file và thư mục con lên thư mục gốc repository, ghi đè file cũ.

Giữ nguyên Supabase. Không cần chạy SQL hay xóa tài liệu/đề. Sau khi upload, mở Admin → chọn đề → cấu hình điểm → Lưu đề → Xuất bản đề để áp dụng cho học sinh.
